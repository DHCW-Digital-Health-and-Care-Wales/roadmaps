A compact view of a roadmap's page: prototypes

Static frames of a roadmap's page on a desktop (1280px wide, the navigation open) and a phone (375px), all drawn from one sample roadmap: Appointment booking, with 18 items and 3 unpublished changes, on 18 November 2026. Journey 1 sets the compact view the owner chose, rows, beside today's cards. Journey 2 draws the switch between cards and compact where the owner chose to put it. Journey 3 cuts a card's long text after three lines.

Nothing here works. Each frame's label names its moment and where keyboard focus is. The analysis beside this page, roadmap-compact-view-ux-analysis.md, compares the designs, including the table and the board that were set aside, and lists the decisions.

1. Read and work a roadmap in a compact view

Sam Evans opens Appointment booking to check the plan and move an item. As cards its 18 items run to about eight screens on a desktop and twelve on a phone. Design A is what the page shows once Compact is chosen: the same header, placements, pending marks and foot bar, with each item as a row.

On a desktop a row never wraps: the title, then the start of the description in what room is left, cut with an ellipsis, so Move and Edit stay in view. On a phone the title takes the lines it needs, with no description. The frames show the whole page, the screen once scrolled to Now, that screen with two rows opened, two opened rows whose fields run long, and a Move menu open. Journey 1 draws the switch where design D of journey 2 puts it.

2. Switch between cards and compact

The owner chose design D: the switch sits with the page's actions. From 768px it is a two-part switch on the title's row, before Add an item and More; narrower, one button after Jump to. It is the same at the top and once the header has stuck, and the view chosen is kept on the device.

3. Keep a long card in hand

No limit is set on what a Product Lead writes, so one long description makes a card as tall as it likes, and its neighbour with it. Design G cuts any field of a card that runs past three lines: a text ends in an ellipsis, a list of details stops after its third line, and Show more under it shows the rest in place. An opened row of the compact view follows the same rule (design A's fourth frame). The first frame is today's card with the same text, for comparison.
