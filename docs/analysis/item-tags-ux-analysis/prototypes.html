Item tags: four editors to try

Each is the Tags field of an item's edit form, in an item card as wide as the roadmap page draws one. All four keep the same rules (below) and offer the tags this roadmap's other items carry. They differ in how a tag is added, renamed and removed. Done keeps the tags and shows the card; Edit opens the form again.

Things to try in each
  1. Add “Appointments”, which two other items carry.
  2. Type clinic staff in lower case: it takes the spelling other items use.
  3. Type patients: the item already has it.
  4. Rename “Video consultations” to “Video appointments”.
  5. Remove a tag, then put it back.
  6. Paste Carers, Welsh language.
  7. Do all of it with the keyboard alone, then press Done.
