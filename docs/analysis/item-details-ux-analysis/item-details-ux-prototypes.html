Item details: three editors for a nested list

Each is the Details field of an item's edit form, in an item card as wide as the roadmap page draws one. The public site shows an item's details as a list under “What this covers”, nested up to three levels. All three editors keep the same rules and would write the same text; they differ in how a detail is written, nested, moved and removed. Done keeps the details and shows the card; Edit opens the form again.
